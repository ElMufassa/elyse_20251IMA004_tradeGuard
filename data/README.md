# Data

**Primary dataset:** EUR USD Forex Pair Historical Data (2002-2020), Oanda hourly bid/ask prices, from Kaggle.
Mirror page: https://baselight.app/u/kaggle/dataset/imetomi_eur_usd_forex_pair_historical_data_2002_2019

- Size: 93,084 hourly rows, 12 columns (date, time, bo, bh, bl, bc, bch, ao, ah, al, ac, ach)
- Content: market prices only, no personal data
- Licence: to be checked on the original Kaggle page before the data is loaded

**Optional second dataset:** Exchange Rates: Currencies & Gold (2002-2024), Kaggle.

Raw files and sample rows will be added here in Phase II.
